マーラータン日和 利用規約

制定日：2026年11月25日

改定日：2026年11月25日（第8条にアレルギーと原材料についての記載を追加。お店の評価として送るのは★だけに変更）

第1条（この規約について）

  1. この規約は、GAO DAWEI（以下「運営者」）が提供するアプリ「マーラータン日和」（以下「本アプリ」）のうち、サインインして使う機能の利用条件を定めるものです。
  2. 本アプリは、サインインしなくてもすべての基本機能（具材えらび、見積もり、記録、マイボウル、マップなど）を使えます。サインインは任意です。
  3. サインインした方（以下「ユーザー」）は、この規約に同意したものとします。
  4. 個人に関する情報の取り扱いは、別に定める「プライバシーポリシー」によります。

第2条（アカウント）

  1. アカウントは「Apple でサインイン」で作成します。運営者は Apple から氏名やメールアドレスを受け取りません。
  2. アカウントは本人だけが使うものとし、第三者に使わせたり、譲ったりすることはできません。
  3. 未成年の方は、保護者の同意を得たうえでサインインしてください。
  4. ユーザーは、アプリ内の「設定 › アカウント › アカウントを削除」から、いつでもアカウントを削除できます。削除すると、サーバーに保存されているそのアカウントの情報（ユーザー名、ニックネーム、お気に入り、お店の評価、保存したレシピの情報）は削除され、元に戻せません。端末と iCloud に保存されている記録やマイボウルは削除されません。

第3条（ユーザー名とニックネーム）

  1. ユーザー名は半角の英数字と「_」で3〜20文字、ほかのユーザーと同じものは使えません。変更は30日に1回までです。
  2. ニックネームは20文字までで、いつでも変更できます。
  3. 次のような名前は使えません。
    • わいせつ・差別的・暴力的な表現、他人を傷つける表現を含むもの
    • 運営者や公式であるかのように見せるもの、他人やお店になりすますもの
    • 法令に違反する、または違反を助長するもの
  4. 運営者は、前項にあたると判断した名前を、予告なく変更することがあります。

第4条（お気に入りとお店の評価）

  1. サインインしているあいだにお気に入りに入れたお店は、そのお店の「お気に入り」の人数に数えられます。
  2. お店の評価（★）は、ユーザーが「平均に反映する」ことを選んだ場合にだけ、みんなの平均に含まれます。この設定はいつでも変更でき、反映をやめると、それまでに送った評価はサーバーから削除されます。
  3. 人数や平均は、一定の人数が集まったお店にだけ表示します。表示する数字は、不正を防ぐために運営者が定める方法で計算します。
  4. 評価は、ユーザー自身が実際に利用した感想にもとづいて行ってください。

第5条（運営者に送る情報）

  1. ユーザーが運営者に送った情報（お店の情報の修正・新しいお店の情報、食材の追加リクエストなど）について、運営者は、本アプリの改善、お店や食材の情報の整備のために、無償で利用できるものとします。
  2. 運営者は、送られた情報を確認のうえ、採用するかどうかを判断します。採用をお約束するものではありません。

第6条（禁止事項）

ユーザーは、次のことをしてはいけません。

  1. 評価やお気に入りの数を不正に操作すること（複数のアカウントを使う、依頼や報酬を受けて評価する、お店の関係者が自分のお店の評価を上げる・ほかのお店の評価を下げる、など）
  2. 実際に利用していないお店を評価すること
  3. 他人になりすますこと、他人のアカウントを使うこと
  4. 本アプリやサーバーに過度な負荷をかけること、不正にアクセスすること、プログラムなどで自動的に操作すること
  5. 本アプリを解析・改変すること、本アプリの情報を無断で大量に取得・転載すること
  6. 法令や公序良俗に反すること、運営者や第三者の権利を侵害すること
  7. そのほか、運営者が不適切と判断すること

第7条（利用の停止など）

運営者は、ユーザーがこの規約に違反した、またはそのおそれがあると判断した場合、事前に知らせることなく、評価やお気に入りの削除、名前の変更、アカウントの利用停止または削除を行うことがあります。

第8条（本アプリの情報について）

  1. 本アプリが表示する重さ・金額・カロリーは推定による目安です。実際の重さや金額は、お店での計量と表示が優先されます。
  2. お店の料金ルールやお店の情報は、インターネット上の情報や利用者から寄せられた情報をもとにした目安であり、お店の公式情報ではありません。変更されている場合があります。
  3. 「お気に入り」の人数やみんなの評価は、利用者の主観にもとづくもので、運営者がその内容を保証するものではありません。
  4. 本アプリの食材の情報は、アレルギー物質や原材料の表示ではありません。同じ名前の食材でも、お店によって原材料は異なります。アレルギーのある方や食事に制限のある方は、必ずお店で確認してください。
  5. 本アプリは、医療・栄養に関する助言を行うものではありません。

第9条（サービスの変更・中断・終了）

  1. 運営者は、本アプリの内容を変更し、または提供を中断・終了することがあります。
  2. 終了する場合は、できるかぎり事前にアプリ内でお知らせします。

第10条（免責）

  1. 運営者は、本アプリの情報の正確さ・完全さ・有用さを保証しません。
  2. 本アプリの利用によってユーザーに生じた損害について、運営者は、運営者の故意または重大な過失による場合を除き、責任を負いません。

  2. 変更する場合は、変更の内容と効力が生じる日を、アプリ内のお知らせなどで事前に知らせます。
  3. 効力が生じた日以降にサインインした状態で本アプリを利用した場合、変更後の規約に同意したものとします。同意できない場合は、アカウントを削除することで利用をやめることができます。
